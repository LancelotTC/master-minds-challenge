# Master Minds Challenge

This `master` branch is not the main place to explore the project deliverables.

It only contains the files that are shared between the two working branches:

- `data-visualisation`
- `machine-learning`

The goal of keeping those common files here is development convenience, so both branches can rely on the same base when needed.

## Where To Go

If you want the exploratory analysis and notebooks, switch to:

```bash
git switch data-visualisation
```

If you want the tabular machine-learning pipeline and prediction workflow, switch to:

```bash
git switch machine-learning
```

## Shared Files In `master`

This branch mainly keeps the shared technical base, such as:

- `update_datasets.py`
- `utils.py`
- `requirements.txt`

Use one of the two branches above to access the actual project-specific content and documentation.
